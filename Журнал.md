# Журнал прогресса

Здесь будет вестись запись того, что проихсодит в проекте в формате новостей.

## Создание архитектуры приложения и бэкенда. 

Командой разработичков была создана и описана архитектура бэкенда. В качестве примера того, что было разработано. Прикрепим часть описания. 

Архитектура приложения:

```
backend/
│
├── cmd/
│ └── main.go # Точка входа
│
├── internal/
│ ├── handler/ # HTTP обработчики (контроллеры)
│ ├── service/ # Бизнес-логика
│ ├── repository/ # Работа с БД
│ ├── model/ # Структуры данных
│
├── pkg/ # Общие утилиты (логгер, конфиг)
│
├── config/ # Конфигурация (env)
│
├── migrations/ # SQL миграции
│
└── go.mod
```

Архитектура бэкенда: 

```
Курсы и уроки
GET    /api/v1/courses                  — список курсов (фильтр: method, level)
GET    /api/v1/courses/:id              — детали курса
GET    /api/v1/courses/:id/lessons      — список уроков курса
GET    /api/v1/lessons/:id              — детали урока с упражнениями
```

Также группой тестирования были внесены некоторые замечания, которые они посчитали важным для  рассмотрения заранее, чтобы в будущем не возникло проблем. В качестве примера приведем один из пунктов замечания: 

> Слишком упрощенная подель user_progress. Сейчас мы фиксируем только базовые данные о прохождении уроков, и этого недостаточно для дальнейшего развития системы. Из-за этого мы ограничены в возможностях анализа поведения пользователя. Например, мы не можем глубоко отслеживать ошибки, динамику обучения или слабые места пользователя. Если расширить аналитическую модель, это откроет возможность для более продвинутых функций: адаптивного обучения, системы анализа ошибок, а также персонализированных рекомендаций под каждого пользователя.

В ходе разбора анализа от группы тестирования группа разработки учла замечания и внесла корректировки.

## Анализ целевой аудитории

В ходе работы над проектом дополнительно была создана группа маректинга. Им назначили задания для составления опроса иностранных студнетов. Группа сформулировала вопросы, варианты ответа для более глубого анализа. 

Изначально опрос был создан для иностранных студентов внутри группы создающей приложение, после чего дополнительно этот опрос был отправлен студентам из других нескольких групп. После получения первых результатов группа маркетинга создала новый опрос. Также эта группа связалась с отделом по работе с иностранными студентами, чтобы получить возможность распространить опрос среди большего количества студентов.
