# Game-in-C

Из репозитория codecrafters-io/build-your-own-x была выбрана тематика создания игры (шахматы) на языке C. Для изучения создания технологии с нуля за основу учебных материалов были видео курс, ссылка на которой также находилась в репозитории. 

На основе видео и самостоятельного воспроизведения практической части, будет написано техническое руководство (туториал). Вся документация ведется в формате Markdown. И будет добавлена в ветку doc. 

Все коммиты разделены на тематику или же, если происходят какие-то серьезные изменения в файлах.
