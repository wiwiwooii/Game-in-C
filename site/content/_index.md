# Шахматы на C

Наш проект посвящён разработке шахматной игры на языке программирования C.

Цель проекта — создать программу, которая позволяет двум игрокам играть в шахматы, выполняя ходы по правилам классической шахматной партии.

В рамках проекта мы используем:

- язык C;
- Git и GitHub;
- Markdown;
- Hugo;
- HTML и CSS.

Этот сайт создан для описания проекта, ведения журнала работы и размещения материалов по проектной практике.
